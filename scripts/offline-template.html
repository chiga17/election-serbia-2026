Shpilkin’s graph

Polling stations grouped by turnout. The height of each curve is votes, so a large station counts more than a small one. Sergey Shpilkin drew elections this way to see whether one list’s votes keep climbing after the others have crested.

This file is complete. It does not use a network. Send the file itself; opening it is enough.

Votes by turnout

One column is one percentage point. Hover a column for the count.

Share of valid votes

The line is drawn where a column has at least 1,500 ballots. Thinner columns are dots. Dashed horizontals are each list’s share on the way up the hill.

Every polling station

One dot per station, drawn once for each list that is switched on. Across is turnout. Up is that list’s share of valid votes. Larger stations are drawn slightly larger.
